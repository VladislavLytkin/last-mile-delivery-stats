# Доступность данных

## Источник

В работе используются два обезличенных датасета кейса «Тинькофф: доставки
карт», опубликованного в рамках Национальной олимпиады по анализу данных DANO
2022–2023.

Официальный источник:
[«Базы данных DANO 2022–2023»](https://dano.hse.ru/data2022).

На странице DANO указано, что первые пять опубликованных наборов данных,
включая этот кейс, были предоставлены соорганизатором олимпиады - компанией
«Тинькофф».

## Ожидаемые файлы

Для запуска анализа требуются:

- `application_dataset.csv` - заявки, временные показатели и флаги этапов
  воронки;
- `hexagons_dataset.csv` - гексагоны, даты изменений, регионы и режимы работы
  до и после изменения.

## Структура каталогов

После получения файлов из официального источника разместите их так:

```text
data/
└── raw/
    ├── application_dataset.csv
    └── hexagons_dataset.csv
```

Каталог `data/` не хранится в Git. Файл `data.dvc` фиксирует идентификатор
ожидаемого входного снимка для технической проверки воспроизводимости.

## Права на данные

Лицензия MIT относится только к авторскому программному коду и документации
Владислава Олеговича Лыткина.

Исходные CSV не распространяются этим репозиторием. Репозиторий не
предоставляет отдельную лицензию или разрешение на повторное распространение
датасета. Условия использования следует проверять у официального источника и
правообладателя; на странице DANO для этого набора не указана отдельная открытая
лицензия.

Публичная конфигурация репозитория не содержит адреса DVC-хранилища с исходными
CSV. Локальная настройка DVC пользователем не меняет правовой статус данных и не
делает DVC официальным источником распространения.

## Воспроизводимость

После размещения файлов проверьте загрузку:

```bash
poetry run python -c "from last_mile.io import load_applications, load_hexagons; print(load_applications().shape, load_hexagons().shape)"
```

Полный расчёт требует Python 3.11, Poetry, установленный R, `Rscript` в `PATH`
и R-пакеты `HonestDiD`, `jsonlite`, `readr`:

```bash
poetry install --no-interaction
poetry run python scripts/run_full_recalculation.py
poetry run python scripts/validate_final_outputs.py --full
```

Официальным документированным способом получения исходных файлов остаётся
страница DANO.
